# Excel 物料版本比對與更新系統 MVP 規格

## 已確認方向

MVP 以 `QP-QA-43-08原物料&包材物質清單2026.xlsx` 作為總表格式基準，支援原物料與包材調查表分批、多檔上傳後依序比對。

## 總物料流程

1. 使用者上傳總表。
2. 使用者分別加入原物料與包材調查表批次，可一次加入多份檔案。
3. 每份調查表需填供應商代號與品項/原料名稱，用於判斷是否更新或新增右側橫向供應品項欄位。
4. 系統解析調查表的供應商、調查日期與化學物質列。
5. 系統依序比對原物料批次與包材批次，並更新對應總表工作表。
6. 系統以調查表化學物質細項列比對總表對應工作表的細項列。
7. 化學物質類別與細項類別不由使用者填寫，也不納入比對 key。
8. 使用者人工確認新增、修改、保留或暫不處理。
9. 使用者按 `套用本批修改` 後，系統另存本輪暫存更動版 Excel，原版不得覆蓋。
10. 全部批次完成後，使用者於版本狀態完成本輪更新並定版，系統產生 Search Report。

## 調查表上傳規則

調查表上傳分為 `原物料調查表` 與 `包材調查表` 兩個批次區塊。單份調查表也走批次流程。

每份檔案一列，使用者需填：

- 供應商代號，必填。
- 品項/原料名稱，必填，用來尋找或新增總表右側橫向供應品項欄位。
- 細項名稱，選填，只作備註/輔助，不寫入總表、不納入 key。

同一供應商或品項的下一筆可沿用上一筆資料。

## 物料欄位匹配規則

總表橫向供應品項欄位判斷：

1. 以調查表 `品名Item No.` 或使用者補填品名，搭配使用者補填的供應商代號尋找總表既有橫向欄位。
2. 若找不到相同 `品名 + 供應商代號`，套用時可新增右側供應品項欄位。
3. 化學物質類別與細項類別不作為上傳調查表時的使用者輸入。

## 寬鬆比對

品名比對需先正規化：

- 去除前後空白
- 全形空白轉半形
- 英文字母大小寫統一
- 移除常見符號
- 合併多餘空白
- 支援包含關係
- 支援簡易相似度分數

## 調查表含量轉換

- `無No` 轉為 `No contain`
- `有Yes` 且含量有值，寫入含量原文
- `有Yes` 但含量空白，標示 `含量缺漏／需人工確認`
- 未勾選但含量有值，以含量為準
- `有Yes / 無No / 含量` 三者皆空，標示 `新版未填／需人工確認`，不覆蓋舊值

## 化學物質比對 Key

預設以 `化學物質名稱 + CAS 主號 + 等級` 辨識同一筆化學物質。

CAS 主號只取第一個符合 CAS 格式的值，例如 `7439-92-1`。若 CAS 為 `-`、`同上` 或空白，則降級使用 `化學物質名稱 + 等級`。同一 key 出現多筆時列為 `疑似重複／需人工確認`。

## 差異處理

- 新增：新版調查表有，總表目標欄位沒有。
- 修改：同一化學物質 key 的含有值、等級或允許濃度不同。
- 刪除/停用：總表舊值存在，新版調查表沒有對應資料；不清空、不刪列，使用者確認後寫入 `停用`。
- 相同：key 與比較欄位皆相同。
- 衝突：重複 key、含量缺漏、新版未填、找不到欄位、多候選未選、公式儲存格等。

## Excel 更新規則

- 原版總表必須保留並可下載。
- 更動版總表另存，檔名使用版本編號。
- 只修改使用者選定工作表與欄位。
- 新增化學物質列時插入資料區底部，複製上一列格式與列高。
- 新增列填入 `Item / 化學物質 / CAS / Level`。
- 新增列右側橫向供應品項欄位需全部補值：對應本次供應商代號的欄位填入調查表 `含有值`，非對應供應商欄位填入 `no contain`。
- 其他工作表不得破壞。
- 保留欄寬、列高、凍結窗格、篩選器。
- 若目標儲存格是公式，列為 `公式儲存格／需人工確認`，不自動覆蓋。
- 空白新版值不得覆蓋舊值。

## Search Report

MVP 報告至少包含：

- `Summary`
- `Added`
- `Modified`
- `Inactive`
- `Conflicts`
- `Full Comparison`

`Summary` 需包含總表檔名、調查表檔名、比對時間、供應商代號、物料名稱、工作表、新增/修改/停用/相同/衝突數量。

## 權限

MVP 暫不分角色，不做正式登入。所有內部使用者先可操作完整流程，包含上傳總表、上傳調查表、比對、確認、套用、刪除未使用檔案與下載。

角色與權限分流延後設計；未來若要加入，一般使用者也必須能上傳總表。

## 檔案刪除規則

- 先前已上傳但用不到的檔案可以刪除。
- `用不到` 的 MVP 定義為：不是正在比對或正在套用中的檔案。
- 比對完成後若確認不再需要該上傳檔案，可以刪除。
- 若刪除的檔案被尚未套用的比對工作引用，該工作標示為 `file_deleted`，不能再套用。
- 刪除未使用的總表時，系統同步刪除該檔案上傳時建立的初始版本紀錄。
- 已產生的更動版總表暫不提供刪除。

## 檔案選用規則

- 比對只使用目前比對基準總表與調查表批次，不會拿所有上傳檔案一起比。
- 上傳新總表後可成為本次指定總表；最近上傳清單中的總表/更動版總表需提供 `本次用這份比對` 按鈕。
- 最近上傳清單中的總表/更動版總表若要正式成為系統預設版本，需按 `定為最新總表`，並顯示二次確認。
- 調查表不提供通用 `選用此檔`；調查表必須從 `調查表上傳` 頁加入 `原物料調查表` 或 `包材調查表` 批次，並補齊供應商代號與品項/原料名稱。
- 頁面需顯示目前比對基準與調查表批次數，避免使用者誤以為所有上傳檔都會參與比對。

## 版本比對操作流程

- `上傳` 頁只負責上傳總表與查看最近上傳/下載列。
- `版本比對` 頁顯示三段流程：`目前狀態`、`執行比對`、`確認並套用`。
- `目前狀態` 只顯示目前比對基準與本輪暫存更動版，版本記錄預設收合。
- `執行比對` 顯示目前比對基準、調查表批次數、下一批、處理順序與比對判斷短提醒。
- `確認並套用` 顯示本批差異確認工具列、差異數、差異表格與套用本批修改。
- 使用者先在 `調查表上傳` 頁加入原物料/包材批次；每份調查表必須有供應商代號與品項/原料名稱。
- 供應商代號欄位支援手動輸入、Ctrl+V 與右鍵貼上；貼上時會移除換行並保留前導 0。
- 系統依序比對原物料再比對包材；兩者更新不同工作表，但共用同一份本輪暫存總表。
- 差異確認後按 `套用本批修改`，只套用目前批次已確認差異，並產生本輪暫存更動版。
- 差異確認按鈕保留：`一鍵確認新增與修改`、`暫不處理`、`套用本批修改`。
- 差異表格顯示：勾選、差異、狀態、來源檔案、類型、供應商代號、品項名稱、化學物質、CAS、Level、修改欄位；不顯示項次。
- 若仍有下一批，下一次比對預設使用本輪暫存更動版。
- 最新版定版只在所有批次完成後，由使用者於版本狀態按 `完成本輪更新並定版`。

## 細項列比對規則

- `品名` 在此業務情境指調查表資料列中的化學原料名稱/化學物質名稱，不等於總表橫向物料欄位名稱。
- 系統不得在比對前要求使用者先選擇要更新哪一個總表物料欄位。
- 使用者只需選擇總表工作表：`原物料` 或 `包材`。
- 系統使用調查表明細列，比對總表所選工作表內既有化學物質細項列。
- 預設 Composite Key 為：`來源 + 化學物質 + CAS主號 + 等級`。
- `等級` 必須納入細項列 key，避免同一化學物質與 CAS 在不同 Level 重複出現時被誤判為衝突。
- `化學物質類別` 與 `細項類別` 不可納入細項列 key，因為總表細項列與調查表細項列的填值來源不同；納入後可能造成整份資料被誤判為全部新增與全部刪除。
- 若完整 key 因 CAS 寫法改變而對不到，但 `來源 + 化學物質 + 等級` 可唯一對應，系統應判定為修改原列，更新該列的 CAS/項次/等級資料。
- 調查表不是總表全量清單；調查表未列出的總表細項不可視為刪除或停用。
- 調查表 `有/無` 與 `含量` 欄位空白時，只做備註警告，不阻擋細項列比對。
- 新增列經人工確認後會追加到總表細項清單底部。
- 修改列經人工確認後會更新總表既有細項列的項次、化學物質、CAS、等級。
- 差異確認動作需符合差異類型：新增可接受新版/確認新增/暫不處理；修改可接受新版/保留舊版/暫不處理。
- 可使用 `一鍵確認新增與修改` 加速流程：新增自動確認新增，修改自動接受新版。

## 橫向供應品項新增規則

- 調查表若提供 `品名/原料名稱` 與 `供應商代號`，系統會用兩者尋找總表既有橫向供應品項欄位。
- 若總表已有相同 `品名 + 供應商代號` 欄位，套用時只更新該欄位的細項含有值。
- 若總表沒有相同 `品名 + 供應商代號` 欄位，套用時在該工作表最右側新增一欄。
- `原物料` 新增欄位表頭填入：第 5 列品名、第 6 列類別、第 7 列供應商代號、第 8 列供應商。
- `包材` 新增欄位表頭填入：第 3 列供應商代號、第 4 列供應商、第 5 列品名。
- 新增欄位會複製原最右欄格式。
- 原物料新增/更新右側品項欄位時使用調查表 `含有值`。
- 包材新增/更新右側品項欄位時使用調查表 `允許濃度`。
- 使用者必須在上傳調查表區填寫 `品名/原料名稱`，系統不再只依賴調查表表頭或檔名推測右側供應品項欄位。

## 總表查詢

- 系統提供 `總表查詢` 分頁。
- 查詢總表來源包含：沿用目前選用總表、從已上傳總表選擇、上傳新的查詢總表。
- 查詢條件包含：工作表、供應商代號、供應商名稱、品項/原料名稱、品項分類、細項化學物質。
- 供應商代號、供應商名稱、品項/原料名稱、品項分類、細項化學物質應從所選總表讀取後產生可輸入建議欄位。
- 結果直接顯示 `細項清單`。

- 預設只顯示該供應品項有填含有值的細項；勾選 `包含未含有/空白資料` 後，`No contain` 或空白也會一起列出。
