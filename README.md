# Excel 物料版本比對與更新系統

這是一個公司內部使用情境下開發的 Excel 物料版本比對與更新系統。系統目標是協助整理每年大量廠商提供的原物料與包材調查表，將化學物質資料彙整至總表，並透過差異比對、人工確認與版本定版流程，降低人工整理時間與版本管理風險。

## 專案背景

原物料與包材物質總表已累積維護多年，每年仍需收集約 200 份廠商調查表。過去主要依靠人工比對與整理，常見痛點包含：

- 新增或修改的化學物質需要逐列查找與比對。
- 原物料與包材調查表格式不同，容易造成整理流程不一致。
- 多人同時編輯或傳遞 Excel 時，可能不清楚誰手上才是最新版。
- 若後續要追溯某筆資料來源，需重新翻找調查表與歷史檔案。

## 系統功能

- 上傳總表並標示目前最新版本。
- 查詢總表中的供應商、品項、分類與化學物質細項。
- 分別上傳原物料與包材調查表。
- 自動比對新增與修改項目。
- 由使用者人工確認後套用修改。
- 產出更動版總表與 Search Report。
- 完成本輪更新後定版，保留版本歷程。
